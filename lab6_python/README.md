# Лабораторная работа 6

Тема 4, подтема 1 (нейросеть обратного распространения ошибки). Вариант 12, задание 12: Δ < 0,0048.

Запуск: двойной щелчок по `run_lab6.bat` – ставит библиотеки, запускает `lab6.py` и собирает отчет.

Исходные данные (43 района: 5 входов и средний доход) записаны в начале `lab6.py` в списке `data`.

Сеть: персептрон 5-8-1, обучение обратным распространением ошибки до |Δ| < 0,0048 на всех обучающих примерах. Обученная сеть сохраняется в `results/network.npz`.

Расчёт по своим значениям: двойной щелчок по `run_predict.bat` (сначала один раз запустить `run_lab6.bat`, чтобы появился `results/network.npz`).
Программа `predict.py` загружает сохранённую сеть, показывает пример и диапазоны, затем в цикле спрашивает 5 значений и печатает средний доход. Выход – пустая строка или `q`.

# Лабораторная работа 6

Тема 4, подтема 1 (нейросеть обратного распространения ошибки). Вариант 12, задание 12: Δ < 0,0048.

Запуск: двойной щелчок по `run_lab6.bat` – ставит библиотеки, запускает `lab6.py` и собирает отчет.

Программа ищет файл `Домохозяйства в районах РТ.xls` (или `.xlsx`) в папке `references` или рядом с программой.
Первая строка листа – заголовки, первый столбец – район, столбец со словом «доход» – выход, остальные числовые столбцы – входы.
Если файла нет, используются **демонстрационные (выдуманные) данные**, и отчет получает пометку `_ДЕМО_ДАННЫЕ`.

Сеть: персептрон 5-8-1, обучение обратным распространением ошибки до |Δ| < 0,0048 на всех обучающих примерах. Обученная сеть сохраняется в `results/network.npz`.

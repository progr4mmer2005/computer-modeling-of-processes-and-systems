# Лабораторная работа 5 — системы массового обслуживания

Вариант 12: банковское отделение с двумя кассирами и одним банкоматом.

Программа автоматически моделирует 10 000 восьмичасовых дней со случайным начальным значением. Текстовый итог сохраняется в `results/results.txt`, графики — в PNG-файлы рядом с ним.

Запуск: дважды щёлкнуть `run_lab5.bat`. BAT-файл устанавливает Matplotlib, выполняет расчёт и обновляет отчёт DOCX.
Для запуска только расчёта: `python -X utf8 lab5.py` (нужен Matplotlib).
Выбранные параметры указаны в начале программы и в отчёте.

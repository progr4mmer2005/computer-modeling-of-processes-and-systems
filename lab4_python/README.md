# Лабораторная работа 4 на Python

Построение аналитической модели по результатам эксперимента, вариант 12,
задание 12: Sr_волосы = f(Sr_воды), прогноз для Sr_воды = 0,424.

## Запуск

Двойной щелчок по `run_lab4.bat`. Скрипт находит Python, ставит библиотеки
из `requirements.txt` и запускает программу.

Вручную:

```powershell
python -m pip install -r requirements.txt
python -X utf8 lab4.py
```

## Что делает программа

1. Печатает исходные данные (29 строк таблицы 1 методички) с промежуточными
   столбцами x², y², x·y и их суммами.
2. Выполняет ручной расчет по формулам методички: A, A0, A1, B, B0, B1,
   коэффициенты прямой и обратной регрессии, коэффициент корреляции r, R²,
   несмещенные дисперсии, доверительные интервалы по Стьюденту с округлением.
3. Строит по формулам методички гиперболу, экспоненту и параболу.
4. Строит все модели линии тренда Excel: линейную, полиномиальные 2–6 степени,
   логарифмическую, степенную и экспоненциальную. Сравнивает их по R²,
   скорректированному R², F-критерию и скользящему контролю (LOO).
5. Выполняет статистическое оценивание линейной модели: стандартные ошибки,
   t- и F-критерии, интервалы для коэффициентов и прогноза, анализ остатков.
6. Ищет модель с R² ≥ 75 % и показывает, почему прогноз недопустим.
7. Создает книгу `results/lab4_excel.xlsx`: формулы ручного расчета, проверку
   встроенными функциями Excel и 6 диаграмм с линиями тренда (уравнение и R²
   на диаграмме).
8. Если установлен Microsoft Excel, запускает `excel_export.ps1`. Скрипт
   пересчитывает книгу в Excel и сохраняет скриншоты листов и диаграмм
   (`excel_*.png`). Без Excel этот шаг пропускается.

Все результаты лежат в `results`: `results.txt`, `results.json`, графики PNG и книга Excel.

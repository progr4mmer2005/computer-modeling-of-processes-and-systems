# Лабораторная работа 4

Вариант 12, задание 12: зависимость Sr_волосы от Sr_воды, прогноз для Sr_воды = 0,424.

Запуск: двойной щелчок по `run_lab4.bat`. Он ставит библиотеки (numpy, scipy, matplotlib) и запускает `lab4.py`.

Программа печатает ручной расчет линейной регрессии, пять моделей с R², тесноту связи и статистическую оценку, обратную регрессию с доверительными интервалами, вывод о прогнозе, гиперболу и полиномы разных степеней. Графики сохраняются в папку `results`.

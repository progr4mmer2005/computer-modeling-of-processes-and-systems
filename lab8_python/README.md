# Лабораторная работа 8

Тема 4, подтема 3 (система нечеткого вывода Мамдани). Вариант 12, задание 4 (вариант 4 функций принадлежности выхода).

Запуск: двойной щелчок по `run_lab8.bat` – ставит библиотеки, запускает `lab8.py` и собирает отчет.

1. Экосистема: 4 входа, 256 правил, три набора параметров функций принадлежности (zmf, pimf, pimf, smf).
2. Кондиционер MITSUBISHI HEAVY SRK25ZJP-S: входы Δt и Vt, 9 правил, выход – частота компрессора (вершины 1,5; 35; 68; 101; 134 Гц).
3. Сравнение вариантов 1–4 функций принадлежности выхода.

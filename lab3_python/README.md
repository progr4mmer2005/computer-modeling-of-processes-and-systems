# Лабораторная работа 3 на Python

Динамические аналитические модели, вариант 12: общие задания 1–3 и
индивидуальное задание 4 (стабилизация самолета по крену).

## Запуск

Двойной щелчок по `run_lab3.bat`. Скрипт сам находит Python, ставит
библиотеки из `requirements.txt` (numpy, scipy, matplotlib) и запускает программу.

Вручную:

```powershell
python -m pip install -r requirements.txt
python -X utf8 lab3.py
```

## Что делает программа

- Решает каждую систему двумя решателями: `ode23` — RK23 (метод
  Богацки–Шампина) и `ode113` — многошаговый метод Адамса переменного порядка (VODE).
- Для каждого задания решает три варианта: базовый, с другим интервалом
  интегрирования и с другими начальными условиями. Базовый вариант
  дополнительно считается со строгой точностью.
- Все системы линейные, поэтому программа считает точное решение через
  матричную экспоненту и по нему оценивает погрешность каждого решателя.
- Печатает таблицы покоординатного сравнения, статистику решателей (шаги,
  вызовы правой части, погрешность) и значения в конце интервала.
- Для задания 4 находит время установления, максимумы координат и сигнал
  управления и сравнивает движение с регулятором и без него.
- В папке `results` создает `results.txt` (весь вывод), `results.json`
  (данные для отчета) и 19 графиков PNG.

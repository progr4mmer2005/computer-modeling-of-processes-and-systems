# Лабораторная работа 7

Тема 4, подтема 2 (карта Кохонена). Вариант 12, задание 2.

Запуск: двойной щелчок по `run_lab7.bat` – ставит библиотеки, запускает `lab7.py` и собирает отчет.

Программа ищет файл `Банковские депозиты (вклады).xls` (или `.xlsx`) в папке `references` или рядом с программой.
Первая строка листа – заголовки, первый столбец – регион, остальные столбцы – признаки.
Если файла нет, используются встроенные данные из программы.
Анализируемый объект (`TARGET`) и регионы для сравнения (`COMPARE`) заданы в начале программы.

Карта 3×3, признаки логарифмируются и нормируются в [0; 1].

# Лабораторная работа 2 на Python

Вариант 13, задание 3. Все данные заданы константами в `lab2.py`.

Один раз установите библиотеку из этой папки:

```powershell
python -m pip install -r requirements.txt
```

Запуск:

```powershell
python lab2.py
```

В Windows можно также открыть `run_lab2.bat` двойным щелчком.
Для Python Launcher команды: `py -3 -m pip install -r requirements.txt` и `py -3 lab2.py`.

Программа считает постоянную часть, проверяет знаки функции, решает уравнение
методом половинного деления при четырех значениях ε, печатает ASCII-таблицу,
проверяет обратную замену x = y² и полную исходную модель.
В папке `results` появляются текстовые результаты, JSON и три графика PNG.
Ничего вводить при запуске не нужно. Расчеты используют стандартную библиотеку;
matplotlib нужен для картинок.

Остановка метода: половина ширины интервала не превышает ε.
Это оценка погрешности аргумента в мг/л, а не ограничение на невязку f(x)
и не эквивалент системной переменной TOL в Mathcad.
Для совпадения с записанной в Mathcad функцией постоянная округляется
до девяти знаков; программа отдельно выводит значение до округления.
